Descripción del Proyecto

El Sistema Web de Gestión de Estructuras de Datos fue desarrollado con el propósito de ofrecer una herramienta educativa que permita visualizar, gestionar y comprender los diferentes tipos de estructuras de datos (arrays, pilas, colas, listas, árboles y grafos) de manera interactiva.
El sistema está diseñado para funcionar como una plataforma web dinámica, donde los estudiantes pueden acceder a información teórica, ejemplos prácticos y ejercicios relacionados con cada estructura. Además, permite la administración de contenido mediante un CRUD (crear, leer, actualizar y eliminar), lo que facilita al docente y a los alumnos mantener el material actualizado.

Tecnologías utilizadas:
•	Editor: Visual Studio Code, HTML, CSS, JavaScript, Bootstrap 5
•	Base de Datos: MySQL
•	Servidor local: XAMPP


La organización del proyecto se realizó por módulos, separando el contenido en categorías temáticas (por ejemplo: Arrays, Pilas, Colas, Árboles, Grafos), para facilitar la navegación y la comprensión visual del estudiante.



Decisiones de Diseño

Diseño de tarjetas:
Se optó por un diseño basado en tarjetas (cards) para presentar los temas de forma clara, visual y moderna. Este formato permite que cada estructura de datos tenga su propia tarjeta con descripción, imagen y acceso al contenido detallado, lo que mejora la experiencia del usuario y la estética general del sitio.

División en categorías:
Los contenidos se organizaron por tipo de estructura (Arrays, Pilas, Colas, Listas, Árboles y Grafos). Esta división facilita el aprendizaje progresivo y mantiene el orden lógico de los temas, permitiendo que los usuarios encuentren fácilmente la información que buscan.


Funcionalidades Implementadas

•	CRUD completo (Crear, Leer, Actualizar y Eliminar contenidos) 
•	Autenticación de usuarios (login y registro con validación)
•	Diseño responsivo con Bootstrap 5
•	Búsqueda dinámica en tiempo real
•	Subida de archivos e imágenes
•	Visualización categorizada de los contenidos
•	Panel de administración para gestionar estructuras
•	Sistema modular con conexión MySQL
•	Interfaz intuitiva y adaptada a móviles
